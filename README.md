# ⚡ Astra Academy — IT • AI • PROGRAMMING

Astra Academy — o‘zbek tilidagi zamonaviy dasturlash, sun’iy intellekt va texnologiya ta’lim platformasi (Next.js 14, TypeScript, Tailwind CSS).

---

## 🚀 Texnologiyalar Steki

- **Frontend**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS
- **Dizayn**: Dark / Pitch Black (`#000000`) & Gold Luxury estetika, to‘liq mobil moslashuvchan (Telegram Mini App tayyor)
- **Komponentlar**: Lucide React ikonkalari, Canvas Confetti
- **Arxitektura**: Supabase & PostgreSQL ga tayyor modulli arxitektura, rolga asoslangan boshqaruv (Talaba va Admin)

---

## 🌟 Asosiy Bo‘limlar va Imkoniyatlar

1. **KURSLAR (`/courses`)**:
   - Frontend (HTML, CSS, JavaScript, React, Next.js, TypeScript) va boshqa kurslar
   - Modullar, darslar, YouTube video pleyer, darsni tugatish va coin mukofotlari
2. **JONLI EFIRLAR (`/live`)**:
   - Jonli efirlar, masterklasslar, YouTube Live translatsiyasi, jonli chat va eslatma tizimi
3. **FOYDALI VIDEOLAR (`/videos`)**:
   - Bepul video darsliklar va amaliy qo‘llanmalar to‘plami, toifalar bo‘yicha filtr va popup pleyer
4. **SOVG‘ALAR BO‘LIMI (`/gifts`)**:
   - Kunlik bonuslar (+50 coin), promo-kodlar tizimi, Astra Academy brendli merchlari va kurs vaucherlari
5. **SINOVLAR VA TESTLAR (`/tests`)**:
   - Interaktiv testlar, tushuntirishlar, natijalar tahlili va sertifikatlar
6. **AMALIYOT (`/practice`) VA LOYIHALAR (`/projects`)**:
   - Real loyihalar, starter fayllar va topshiriqlarni topshirish
7. **ADMIN PANELI (`/admin`)**:
   - Kurslar, testlar, loyihalar va talabalar boshqaruvi

## 🛠️ Loyihani Ishga Tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dasturchi rejimida ishga tushirish
npm run dev

# Ishlab chiqarish uchun yig'ish (Production Build)
npm run build
npm run start
```
